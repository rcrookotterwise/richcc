Operating-System Families

Operating systems are designed for different devices and needs. Here are several common categories.

Desktop and laptop systems

These systems support general-purpose computing, including browsing, creative work, and software development. Examples include Windows, macOS, and Linux.

Mobile systems

Mobile operating systems are designed for phones and tablets. They focus on touch input, battery life, wireless connections, and apps. Examples include Android and iOS.

Server systems

Server operating systems provide services such as websites, file storage, and databases. They often run without a desktop interface. Examples include Linux and Windows Server.

Embedded and real-time systems

Embedded operating systems run inside dedicated devices such as appliances and vehicles. Some real-time systems are designed to respond to events within strict time limits.
